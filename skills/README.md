[Agent Skills](https://agentskills.io) layout.

| [`storage-kit`](storage-kit/SKILL.md) | installing storage-kit; declaring keys (values or enums); reading, writing and observing plain or secure values; tokens and sign-out; a debug console over stored values; testing code that stores things |
